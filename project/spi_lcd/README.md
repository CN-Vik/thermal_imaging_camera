# 1. MLX90640原始采集

这里：

```c
MLX90640_GetFrameData()
```

拿到：

```
834 uint16_t
```

其中：

```
0~831
```

是数据。

```
832
```

控制信息。

```
833
```

subpage。

---

MLX90640不是一次输出768点。

它是：

## Chess模式

两个subpage：

```
Subpage 0

● ○ ● ○
○ ● ○ ●
● ○ ● ○


Subpage 1

○ ● ○ ●
● ○ ● ○
○ ● ○ ●
```

两次合起来：

```
32×24=768
```

所以你这里：

```c
subpage_init[2]
```

处理正确。

# 4. Subpage棋盘失配滤波

你的这段：

```c
if(diff >0.8)
```

这是针对 MLX90640 特有问题。


因为：

两个subpage：

```
A:
●○●○

B:
○●○●
```

两个采样时间不同。


运动场景：

可能：

A:

```
人体25℃
```

B:

```
人体26℃
```


合成后：

出现棋盘：

```
25 26 25 26

26 25 26 25
```


你这里：

比较邻居：

```c
avg
```

发现差异：

```c
diff >0.8℃
```

然后融合。

这个思路不错。

# 四、但是还有几个明显不足

如果目标是接近 FLIR / 海曼：

还缺：

---

## 1. NUC非均匀校正

现在：

```
每个像素独立温度
```

但是MLX90640：

不同像素：

存在固定偏差。


例如：

```
pixel1 永远 +0.8℃
pixel2 永远 -0.5℃
```


需要：

offset correction。


---

## 2. 边缘增强


现在：

滤波后：

会糊。


增加：

Unsharp Mask:

```
sharp =
original+(original-blur)*k
```


人体轮廓明显。


---

## 3. 坏帧检测


比如：

I2C异常：

温度：

```
-40℃
```

现在：

主要靠：

```
val >1
val<200
```


可以增加：

CRC / frame validity。


---

## 4. 自动温区


你现在：

```c
20~35℃
```

室内很好。


但是：

室外：

-20℃
或者

发动机：

100℃


不适合。


产品一般：

固定模式+自动模式。
